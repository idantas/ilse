# Contributing to Ilse

Thanks for helping. Issues, ideas and pull requests are all welcome.

**This repo is built with coding agents, and its docs are written for them first.** Open your agent in the repo — it reads [AGENTS.md](AGENTS.md) (Claude Code gets it through `CLAUDE.md`). If you work by hand, read the same file: commands, rules, code map, recipes and what "done" means are all there.

- **Bigger change?** Open an issue first so we can agree on the approach.
- **Security problem?** Report it privately — see [SECURITY.md](SECURITY.md).
- **Pull requests:** one topic each, saying *why* and how you tested it. The checklist in the PR template mirrors "Done means" in AGENTS.md.
- **Reporting a bug:** include OS, Node, framework, agent and the session journal (toolbar → Settings → Logs → copy). The journal has timings and counts only — no notes, prompts, code or paths.
